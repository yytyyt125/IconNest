# IconNest

**绿色免安装 · Windows 桌面图标整理工具**

把杂乱的桌面图标，分门别类收进你的「图标巢」。拖入即分类、单文件分发、开箱即用，无需安装、不写注册表。

> 当前版本 **v0.2.12** · 单文件 exe（约 72 MB）· 开源分发

---

## ✨ 功能特性

- **图标分类收纳**：把桌面或任意位置的图标拖入分类窗口，按你的逻辑归置。
- **图标高清呈现**：与 Windows 资源管理器同源提取图标（含快捷方式、文件夹、Office、图片等），清晰度对齐桌面原生图标。
- **网格自适应布局**：分类窗口内图标按窗口宽度自动调整每行数量，缩放窗口即时重排。
- **手动排序**：拖入后不强制自动排序，图标的前后顺序由你掌控。
- **绿色便携**：单文件 exe，放到任意目录双击即用；分类数据可一键迁移到任意位置（含 U 盘）。
- **实时透视背景**：分类窗口支持半透明实时背景，整理时不错位。

## 📥 下载与安装

前往 **[Releases](https://github.com/yytyyt125/IconNest/releases)** 页面，下载 `IconNest.exe`（v0.2.12）即可。

- 无需安装，下载后直接双击运行。
- 建议放在你有写入权限的普通目录；若放入 `C:\Program Files` 等受保护目录，写配置可能失败，可改用右键「以管理员运行」或换目录。

## 🚀 快速使用

1. 双击 `IconNest.exe` 启动，程序驻留系统托盘。
2. 从托盘右键菜单打开「分类窗口」。
3. 将桌面或其他位置的图标拖入分类窗口。
4. 在设置中可调整分类文件存储位置、窗口外观等。
5. 关闭窗口即收起，图标分类数据自动保存。

---

## 📁 分类文件存储位置

- **默认位置**：程序首次运行时，会根据你当前用户的桌面所在盘根自动生成分类目录（例如桌面在 `C:\Users\你的用户名\Desktop`，则默认目录为 `C:\IconNest 分类文件`）。**不会指向开发者的机器路径。**
- **修改位置（图形界面，推荐）**：托盘右键 → 设置 → 「分类文件存储位置」→ 点「更改…」→ 选择新文件夹。程序会自动把现有分类夹整体迁移过去（跨盘为复制+删除，带失败回滚）。
- **修改位置（手动）**：编辑 exe 同级目录下的 `config\config.json`，将 `settings.storageRoot` 设为目标绝对路径，重启生效。
- **配置文件位置**：`config.json` 位于 **exe 同级目录**；单文件 exe 下即 exe 所在文件夹。

## ❓ 常见问题

**Q：这是开源项目吗？源码在哪里？**
A：本仓库当前仅分发编译好的 exe 与说明文档。源码采用独立仓库/本地管理，如需源码可联系作者。

**Q：为什么 exe 有 70 多 MB？**
A：这是 .NET 自包含（self-contained）单文件发布，内嵌了运行所需的一切，因此不依赖系统是否安装 .NET 运行时，代价是体积较大。

**Q：支持哪些 Windows 版本？**
A：面向 Windows 10 / 11 的 64 位系统（x64）。

**Q：杀毒软件误报怎么办？**
A：单文件自包含程序偶尔会被误报。可从 Releases 页校验文件，或将本程序加入信任/白名单。
